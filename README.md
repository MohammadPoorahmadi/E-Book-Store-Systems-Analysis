# E-Book Store: Systems Analysis & Design

## Project Overview
This project covers the full analysis and design phase of an E-book store system. It focuses on translating business requirements into technical blueprints using industry-standard modeling techniques.

## Key Design Artifacts
* **Requirements Engineering**: Defined functional and non-functional requirements for customers and administrators.
* **UML Modeling**: Created Use Case Diagrams, Class Diagrams, and Sequence Diagrams to map system logic.
* **System Architecture**: Designed the structural flow of the bookstore's operations.
* **UI/UX Design**: Developed a high-fidelity user interface prototype.



## UI Prototype
